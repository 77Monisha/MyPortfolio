# Monisha Chaurasia — Portfolio

Personal portfolio site built with Next.js (App Router), React, and Tailwind CSS.

## Routes

- `/` — Professional view: a GitHub-style profile (README, repositories, commit history, skills, contact).
- `/p1` — Developer view: a more detailed portfolio (hero, about, experience, projects, skills, contact).
- `/original-home` — the previous homepage, kept for reference.

Most content lives in [`lib/portfolio-data.js`](lib/portfolio-data.js).

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```
